# 💰 MyTabungan

MyTabungan is a simple web-based personal finance management application designed to help users manage their daily finances by recording income, expenses, and transactions.

## ✨ Features

- 🔐 User Registration & Login
- 💵 Record Income
- 💸 Record Expenses
- 📋 View Transaction History
- 🗑️ Delete Transactions
- 👤 Account Management
- 🚪 Logout

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## 🚀 How to Run

1. Clone or download this repository.
2. Move the project folder to the `htdocs` folder in XAMPP.
3. Start **Apache** and **MySQL** from XAMPP.
4. Open **phpMyAdmin**.
5. Create a database named `tabungan`.
6. Import the `if0_41880054_tabungan.sql` file.
7. Make sure the database configuration in `koneksi.php` is set to your local MySQL settings.
8. Open the application in your browser:

   `http://localhost/mytabungan/login.php`

**MyTabungan** was developed as a school project for **PPLG (Pengembangan Perangkat Lunak dan Gim)**.

The project focuses on creating a simple database-driven web application for personal financial management.
